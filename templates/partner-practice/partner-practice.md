# Partner practice plan

Regular speaking with a fixed partner is a core part of the method. In the program that inspired it, learners were paired in their first year and practised speaking together twice a week during the semester, and more if they wanted. This template helps you set up something similar. The numbers below are examples to adapt, not rules.

> Why: classroom learning becomes spoken language through repeated speaking in low-pressure conversation. A fixed partner means no one has to start from nothing each time, and no one is left out.

## 3. Session outline

Each session can follow the same simple shape so learners don't need the teacher to run it. Example:

1. **Sounds (2 min):** say the sounds from today's round to each other.
2. **Warm-up (5 min):** greet, and ask and answer the pattern from the last lesson.
3. **Task (10–15 min):** the partner task from the lesson template, for example a conversation about the real object or place in the lesson.
4. **Switch roles:** each person asks and answers.
5. **Log (2 min):** note what you did and one thing you found hard.
