# Indigenous Language Framework

A free, open toolkit that helps Indigenous communities turn their own language materials into structured, teachable curriculum.

**Status: early planning (v0). Nothing here is finished or ready for classroom use yet.**

## What this is

Many Indigenous language programs have people who know the language, recordings, and a strong will to teach, but lack a structured curriculum to hold it all together. Building one from scratch is slow and requires specialist skills that small programs often can't afford.

This framework provides the **structure and method**. The community provides the **language, stories, and knowledge**.

It is a lesson-building toolkit, not a set of ready-made lessons. We do not supply vocabulary, grammar, or cultural content for any language. That belongs to the community and is decided by the community.

## Who it's for

The primary user is a **language coordinator or teacher inside a community**, not a software developer. Everything here should be usable by someone comfortable with documents and spreadsheets. Where code is involved, it should run from simple instructions and its output should work offline and print on paper.

## What the toolkit will include

- A **method guide** explaining the teaching approach and why each part is there
- **Templates** for scope and sequence, units, lessons, speaker visits and partner practice
- A **content schema** for organizing words, sentences, audio, grammar notes and stories
- **Scripts** that turn that content into lesson pages, flashcards and printable PDFs
- A **demo in a fictional language**, so no real community's content is used as the example
- Later: an online tool at michifai.ca built on what the toolkit has proven

## The approach in brief

The method is inspired by the author's experience learning Chinuk Wawa in the Lane Community College program in Oregon. Its main ideas:

1. Lessons build in a deliberate order, each assuming the last
2. Speaking, listening, reading and writing are mixed throughout, from single words up to short essays
3. Grammar and word order are introduced gradually and reinforced through use
4. Learning is anchored in real objects, local stories and the surrounding world
5. Learners practise with partners on a regular schedule
6. Speakers, elders and culture-bearers are part of the program, so learners connect with people and history, not only the language
7. Each session begins with the alphabet and sounds

See [DESIGN.md](DESIGN.md) for the full reasoning.

## Your community's data stays yours

**Please read [PROTOCOLS.md](PROTOCOLS.md) before adding any community material.**

The intended way to use this project is to copy it into your own **private** repository using GitHub's "Use this template" feature. Your language content then never touches this public repository. Nothing community-specific should ever be submitted here.

## Who is behind this

Created and maintained by Darrin (Michif AI Partners, Red River Métis-owned). The project begins with pilot work alongside Chinuk Wawa and Southern (heritage) Michif communities. If it grows, an advisory group of Indigenous language leaders may be formed to guide it.
